# TASK表 スクリプト

「TASK 202608-202609」スプレッドシート用の Apps Script です。

| ファイル | 内容 |
| --- | --- |
| `Menu.gs` | 「タスク表」メニューと自動処理の設定 |
| `ArchiveCompleted.gs` | 完了タスクを「完了」タブへ移す |
| `Integration.gs` | 「TASK表 統合」タブを自動でまとめる（統合タイムラインの元データ） |
| `Dashboard.gs` | 期日が近いタスクを一覧する「ダッシュボード」タブを作る |
| `DeadlineColors.gs` | 各タブと統合タブの行を、期日の近さでダッシュボードと同じ色に塗る |

## 導入手順

1. スプレッドシートで「拡張機能 → Apps Script」を開く
2. 4つのファイルをそれぞれ同じ名前で作り、中身を貼り付けて保存（`ArchiveCompleted.gs` は既存の `コード.gs` でも可。ただし `onOpen` は `Menu.gs` にだけ置く）
3. スプレッドシートを再読み込み → メニュー「タスク表」から
   - 「統合タブを作り直す」
   - 「ダッシュボードを作り直す」
   - 「自動処理を設定」
   を一度ずつ実行

## 完了タスクのアーカイブ

- A列から `項目 / Task / 状況詳細 / 担当 / 開始 / 期日 / 残日数 / 状態 / 重要度 / URL1 / URL2 / ステータス` の見出しが並ぶタブが対象です。
- 「ステータス」が「完了」の行だけを移します。「状態」だけが「完了」の行は残します。
- 「完了」タブの末尾に `元タブ / アーカイブ日` を付けて追加し、元のタブからは削除します。「元タブ」は移動元タブへのリンクです。
- 「完了」タブがなければ自動で作ります。

## 統合タブ（TASK表 統合）

- 「TASK表」で始まるタブ（`TASK表 統合` と `TASK表 Archive` を除く）を1つの数式でまとめます。
- 各タブの行の追加・削除・編集は、数式がそのまま拾います。範囲を手で直す必要はありません。
- カテゴリ列はタブ名から自動で入ります。名前を変えたい場合は `Integration.gs` の `CATEGORY_ALIASES` に書きます。
- 期日が入っている行だけを期日順に並べます。残日数は「期日 − 今日」で計算します。開始が空の行は、タイムラインに載るように開始＝期日で出します。
- タブを追加・削除・改名したときは、自動処理（onChange トリガー）か、ファイルを開いたときに数式を書き直します。

## ダッシュボード

- 表示する日数（E2）以内に期日が来るタスクと、期限切れのタスクを期日順に並べます。ステータスか状態が「完了」の行は出しません。
- 担当（H2）を選ぶと、その人のタスクだけに絞れます。
- 期限切れ・今日・1〜3日後・4〜7日後の件数を上部に出し、行も同じ色で塗り分けます。
- 数式で動くので、開くたび・編集するたびに最新になります。

## 各タブの期日の色

- 各 TASK表 タブと統合タブの行を、ダッシュボードと同じ4色（期限切れ・今日・1〜3日後・4〜7日後）で塗ります。条件付き書式なので、日付が変わると色も自動で変わります。
- ステータスか状態が「完了」の行は塗りません。
- もともと付いている条件付き書式は残します。
- 新しいタブは、見出しを入れたあとスプレッドシートを開き直すと自動で色が付きます（メニューから手動でも可）。

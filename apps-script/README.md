# TASK表 完了タスクのアーカイブ

「TASK 202608-202609」スプレッドシートの各プロジェクトタブから、完了した行を「完了」タブへ移すための Apps Script です（記載ルール「7．完了したタスクの扱い」：完了行は削除せず、週次で完了タブへ移して履歴として残す）。

## 動作

- 対象は、A列から `項目 / Task / 状況詳細 / 担当 / 開始 / 期日 / 残日数 / 状態 / 重要度 / URL1 / URL2 / ステータス` の見出しが並ぶタブ（見出しは上から5行目までで探します）。
  - 全体タブ（先頭が「カテゴリ」）、記載ルールタブ、Google ToDo 連携タブ（先頭が「リストID」）は構成が違うため対象外です。
- 「ステータス」が「完了」の行だけを移します。「状態」が「完了」でも、「ステータス」が「完了」でなければそのまま残します。
- 移した行は「完了」タブの末尾に、`元タブ / アーカイブ日` の2列を先頭に付けて追加します。「元タブ」列には移動元のタブ名が入り、クリックするとそのタブへ移動できます（あとでタブ名を変えてもリンクは切れません）。移した直後にも、どのタブから何行移したかを表示します。書式やリンクはそのまま残り、残日数などの数式は値に変わります。
- 元のタブからは行を削除します。全体タブは各タブを参照しているので、自動的に表示から消えます。
- 「完了」タブがなければ自動で作ります。

## 導入手順

1. スプレッドシートで「拡張機能 → Apps Script」を開く
2. `ArchiveCompleted.gs` の内容を貼り付けて保存
3. スプレッドシートを再読み込みすると、メニューに「タスク表」が出ます

## 使い方

| メニュー | 内容 |
| --- | --- |
| 完了タスクを完了タブへ移す | タブごとの件数を確認してから移します |
| 移す対象を確認する（移動しない） | 件数だけ表示します |
| 毎週月曜の自動アーカイブを設定 | 毎週月曜 7時台に自動で移します（初回は権限の承認が必要） |
| 自動アーカイブを解除 | 上の自動実行を止めます |

タブ名を変えたいときは、スクリプト先頭の `ARCHIVE_SHEET_NAME` / `EXCLUDED_SHEETS` を編集してください。
